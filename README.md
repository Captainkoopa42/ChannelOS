# ChannelOS Bloat

This is the docs-only shelf for ChannelOS ideas, planning material, historical
notes, and documents that do not belong exclusively to one runnable product
branch.

This branch is intentionally **not a ChannelOS build**. It contains no
application source tree and should not be used for releases or testing.

Runnable development remains separated by purpose:

- `agent/broadcaster-channel-builder` — expanded offline ChannelOS
- `ChannelOS-for-Linux` — Linux compatibility and packaging
- `ChannelOS-for-macOS` — macOS compatibility and packaging
- `ChannelOS-for-Jellyfin` — optional Jellyfin-backed ChannelOS

Platform- or edition-specific implementation documents should live with their
corresponding branch. General concepts and retired planning material may be
preserved here without bloating the active builds.
