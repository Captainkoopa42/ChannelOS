# Uploading this ChannelOS seed to GitHub

**Status:** Historical bootstrap note — the repository already exists and normal branch/PR development is in use.

These were the original seed-upload instructions:

1. Create the empty `ChannelOS` repository on GitHub.
2. Extract the seed ZIP locally.
3. Open the extracted `channelos_github_seed` folder.
4. Upload **the contents of the folder** to the repository root, not the ZIP itself.
5. Commit the upload as the initial ChannelOS foundation.

This procedure is no longer part of the active development workflow. Current contributors should use ordinary branches, commits, tests, and pull requests and should begin with `README.md`, `docs/MASTER_DESIGN.md`, and `CONTRIBUTING.md`.
