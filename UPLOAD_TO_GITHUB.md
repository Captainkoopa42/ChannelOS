# Uploading this ChannelOS seed to GitHub

1. Create the empty `ChannelOS` repository on GitHub.
2. Extract this ZIP locally.
3. Open the extracted `channelos_github_seed` folder.
4. Upload **the contents of the folder** to the repository root (not the ZIP itself).
5. Commit the upload as the initial ChannelOS foundation.

After that, the repository is ready for normal branch/commit development.
