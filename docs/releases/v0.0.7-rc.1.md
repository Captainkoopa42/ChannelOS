# ChannelOS 0.0.7 — Broadcast Planner test candidate

This candidate adds the native Broadcast Planner from the Unified Broadcast
Planner v0.3 plan and v0.4 interactive concept. It is a third authoring path in
Broadcaster, alongside Classic Builder and Manual Studio.

- Smart Media Bin, shared primary progression, separate reruns, per-media loops,
  strict/custom brackets, explicit bounded overruns, carryover and next-fit.
- Day/week/seasonal views, exact-date and seasonal precedence, scoped pauses,
  protected manual blocks, and read-only forecasts with confidence and milestones.
- ALL/ANY/custom content gates, optional date gates, safe calendar boundaries,
  manual release, Air Once & Done, and preserved closed-cycle history.
- Named, media-independent time-block profiles, pinned versions and channel-local
  assignments, duplicate/import/export, and explicit reapplication previews.
- User-supplied CSV/JSON original-airing records and provenance, owned-media
  substitutes, historical replay and explicitly approximate era recreation.
- One shared compiler for authoring, Guide and ChannelRuntime; actual-time
  checkpoints and failure records; previews never earn airings or completions.

Open **Broadcaster → New Planner** or **Open Planner**. Add a collection as a
track; adding the same collection again creates another shared airing. Choose
Rerun for an independent cursor. Review Forecast and Channel Cycle, then Apply.
Advanced nested gates, exact targets, local overrides and historical substitutions
are also available in the complete Rules editor.

Existing schema 0.1–0.6 channels remain supported. Planner channels use schema
0.7; runtime data advances to schema 4 with the existing database backup policy.
Retain a copy of the setup before testing an upgrade. The prior RC4 release is
not replaced, and no production branch is merged by this candidate workflow.

Forecast work is cancellable and bounded. Unresolved dates are labelled Estimated
or Blocked. Monthly views return calendar totals; detailed event payloads are
limited to nearby views and 3000 rows. No hashing, probing or decoding is done
by the forecast compiler. Windows and Unix use the same packaged time-zone data.

Windows publication must pass the regression suite, package/license audit, native
VLC ad smoke, native Planner smoke, staged startup and portable relocation.
See `WINDOWS_0.0.7_ACCEPTANCE.md` for the physical-device test route.
